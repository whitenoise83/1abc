\section{Frozen Stage-Specific Forecast Policies}

\label{app:policies}

The tables below reproduce the development-sample policy freeze used in H2.

``Different'' identifies the target--stage cells in which the frozen stage
policy and the target-level fixed comparator select different models. There
are 11 such cells out of 36; the remaining 25 cells are mechanical ties in H2.

The stage policy is selected separately within each target--stage common
development sample by minimum MSE, then MAE, then model name for ties within
\(10^{-12}\). The fixed comparator is selected once per target by applying the
same rule to the pooled common development samples across all stages.
