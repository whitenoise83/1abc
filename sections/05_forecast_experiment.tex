\section{Pseudo-Real-Time Forecast Experiment and Evaluation}
\label{sec:experiment}

\subsection{Forecast-origin reconstruction}
\label{subsec:forecast_origin}

For each historical forecast origin $t$:
\begin{enumerate}[leftmargin=*]
    \item determine the information cutoff and forecast stage $s$;
    \item reconstruct the historically feasible information set $\It_{t,s}$;
    \item estimate each permitted candidate model using only information in $\It_{t,s}$;
    \item generate and store point forecasts and predictive intervals;
    \item advance to the next forecast origin without revising stored forecasts;
    \item evaluate forecasts only after the corresponding target outcome becomes observable.
\end{enumerate}

\subsection{No-look-ahead restrictions}
\label{subsec:no_lookahead}

The core restriction is
\begin{equation}
    \max_j\left\{r_{j,\tau}^{(v)}\right\}
    \leq t
    \qquad
    \text{for every observation entering }\It_{t,s}.
    \label{eq:no_lookahead}
\end{equation}

Model-selection histories, combination weights, calibration errors, and all other adaptive quantities are subject to the same restriction. A historical forecast is stored as an immutable object and is not recomputed after later data releases or revisions become available.

\subsection{Policy-development and final evaluation samples}
\label{subsec:development_evaluation}

The stage-dependent policy and the fixed-model comparator used in H2 are selected independently of the observations used for the final confirmatory comparison. Let $\mathcal{T}_{D}$ denote the policy-development sample and $\mathcal{T}_{E}$ the final evaluation sample, with
\begin{equation}
    \max(\mathcal{T}_{D}) < \min(\mathcal{T}_{E}).
    \label{eq:development_split}
\end{equation}
The stage policy $\mathcal{P}(k,s)$ and fixed comparator $m_k^{F}$ are determined using only $\mathcal{T}_{D}$ and are frozen before forecasts in $\mathcal{T}_{E}$ are evaluated. For GDP, development spans 2015Q1--2022Q4, 2023Q1 is an embargo quarter, and confirmatory evaluation spans 2023Q2--2026Q1. For inflation, development spans February 2020--December 2022, January 2023 is embargoed, and evaluation begins in February 2023. For labour targets, development runs through December 2022, January 2023 is embargoed, and evaluation begins in February 2023. These splits were frozen before confirmatory H1--H4 results were opened.

\subsection{Forecast errors and loss functions}
\label{subsec:forecast_errors}

For target $k$, model $m$, stage $s$, and horizon $h$,
\begin{equation}
    e_{k,t+h,s}^{(m)}
    =
    y_{k,t+h}
    -
    \widehat{y}_{k,t+h\mid t,s}^{(m)}.
    \label{eq:forecast_error}
\end{equation}

The primary loss function is squared error,
\begin{equation}
    L_2(e)=e^2,
    \label{eq:squared_loss}
\end{equation}
with absolute-error loss,
\begin{equation}
    L_1(e)=|e|,
    \label{eq:absolute_loss}
\end{equation}
used as a robustness criterion.

\subsection{Point forecast evaluation}
\label{subsec:point_metrics}

\begin{align}
    \RMSE^{(m)}
    &=
    \sqrt{\frac{1}{N}\sum_{i=1}^{N}e_i^2},
    \label{eq:rmse}\\
    \MAE^{(m)}
    &=
    \frac{1}{N}\sum_{i=1}^{N}|e_i|,
    \label{eq:mae}\\
    \Bias^{(m)}
    &=
    \frac{1}{N}\sum_{i=1}^{N}e_i.
    \label{eq:bias}
\end{align}

Relative RMSE against benchmark $b$ is
\begin{equation}
    rRMSE^{(m)}
    =
    \frac{\RMSE^{(m)}}{\RMSE^{(b)}}.
    \label{eq:relative_rmse}
\end{equation}
Values below one indicate lower RMSE than the benchmark.

\subsection{H1: marginal value of information arrival}
\label{subsec:h1_design}

H1 is evaluated by holding model $m$ fixed and comparing the same forecast target across adjacent information stages. For stages $s$ and $s+1$,
\begin{equation}
    d_{k,t}^{H1}(m;s,s+1)
    =
    L\!\left(e_{k,t,s+1}^{(m)}\right)
    -
    L\!\left(e_{k,t,s}^{(m)}\right).
    \label{eq:h1_experiment_diff}
\end{equation}
The confirmatory test is based on the mean paired squared-error differential, with the corresponding absolute-error differential reported as a secondary loss metric. RMSE and MAE are retained as descriptive accuracy summaries. A negative loss differential indicates improved accuracy at the later stage. Comparisons are paired at common target periods so that sample composition does not drive the result, and adjacent-stage pairs with identical information-set hashes are excluded from H1.

\subsection{H2: stage-dependent versus fixed-model policies}
\label{subsec:h2_design}

For target $k$, the stage-dependent forecast is
\begin{equation}
    \widehat{y}_{k,t,s}^{\mathrm{stage}}
    =
    f_{m^*_{k,s}}\!\left(\It_{t,s};\widehat{\theta}_{m^*_{k,s},t}\right),
    \label{eq:h2_stage_forecast}
\end{equation}
while the fixed-policy forecast is
\begin{equation}
    \widehat{y}_{k,t,s}^{\mathrm{fixed}}
    =
    f_{m_k^{F}}\!\left(\It_{t,s};\widehat{\theta}_{m_k^{F},t}\right),
    \label{eq:h2_fixed_forecast}
\end{equation}
where the same fixed model $m_k^{F}$ is used at all stages. Both policies use the identical real-time information set at each forecast origin. Consequently, the H2 comparison isolates model-policy choice rather than information availability.

The confirmatory comparison uses paired squared-error differentials between the stage policy and the fixed comparator, with absolute-error differentials as a secondary loss metric. Negative values favour the stage-dependent policy. RMSE and MAE are also reported descriptively. Cells in which the frozen stage policy and fixed comparator select the same model are exact mechanical ties and are separated from the informative H2 comparisons.

\subsection{H3: real-time versus latest-vintage counterfactual}
\label{subsec:h3_design}

H3 uses two otherwise identical forecast experiments. The real-time system uses $\It_{t,s}^{RT}$, containing only vintages historically available at origin $t$, while the counterfactual replaces eligible historical observations with latest-vintage values $\It_{t,s}^{LV}$ subject to the same observation-date and stage structure:
\begin{align}
    \widehat{y}_{k,t,s}^{RT}
    &=f_m\!\left(\It_{t,s}^{RT};\widehat{\theta}_{m,t}^{RT}\right),
    \label{eq:h3_rt_forecast}\\
    \widehat{y}_{k,t,s}^{LV}
    &=f_m\!\left(\It_{t,s}^{LV};\widehat{\theta}_{m,t}^{LV}\right).
    \label{eq:h3_lv_forecast}
\end{align}

The confirmatory loss differential is
\begin{equation}
    d_{k,t,s}^{H3}
    =
    L\!\left(e_{k,t,s}^{LV}\right)
    -
    L\!\left(e_{k,t,s}^{RT}\right),
    \label{eq:h3_experiment_loss}
\end{equation}
so negative values indicate lower loss under latest-vintage data. The analysis also records forecast-value revisions,
\begin{equation}
    \Delta \widehat{y}_{k,t,s}^{vintage}
    =
    \widehat{y}_{k,t,s}^{LV}
    -
    \widehat{y}_{k,t,s}^{RT}.
    \label{eq:h3_forecast_change}
\end{equation}
Stage-level inference uses every available paired real-time/latest-vintage cell. Target-level summaries average across stages only for target periods with a complete stage set. Candidate-model ranking sensitivity is not part of the present H3 analysis.

\subsection{Statistical forecast comparison}
\label{subsec:forecast_tests}

For paired forecasts, define the generic loss differential
\begin{equation}
    d_t=L(e_{1,t})-L(e_{2,t}).
    \label{eq:loss_diff}
\end{equation}
Equal predictive accuracy corresponds to $\E[d_t]=0$. The confirmatory H1--H3 archive reports two-sided tests of the mean paired loss differential using a Newey--West heteroskedasticity-and-autocorrelation-consistent long-run variance estimator under the frozen implementation. Direction is interpreted from the sign of the corresponding loss differential. Absolute-error tests use the same paired-HAC construction. The post-confirmatory multiplicity exercise in Section~\ref{subsec:multiplicity} applies Holm adjustment within the predeclared H1--H4 test families; it does not replace the archived unadjusted confirmatory tests.

\subsection{H4: prior-only predictive interval calibration}
\label{subsec:interval_calibration}

H4 evaluates uncertainty around the point forecasts generated by the frozen
research stage policy.  Interval calibration is therefore applied to the same
target--stage--model cells used by the point-forecast experiment rather than
to a separate interval-specific point-forecast policy.

For a current forecast origin \(t\), target \(k\), stage \(s\), and frozen
selected model \(m_{k,s}\), let
\(\mathcal{E}^{-}_{k,s,t}\) contain historical forecast errors from the same
target, stage, and model for which the corresponding outcome had already
become observable.  A historical error \(e_i\) is admissible only when its
recorded outcome release date \(a_i\) satisfies
\begin{equation}
    a_i < t.
    \label{eq:h4_release_gate}
\end{equation}
Thus an earlier target period is not sufficient for calibration: its
realisation must also have been released strictly before the precise current
forecast date.  After applying this gate, admissible errors are ordered by
release date and the most recent domain-specific calibration window is used.
Development, embargo, and earlier evaluation errors can enter the calibration
history once they satisfy \eqref{eq:h4_release_gate}.

All H4 intervals are central 80\% intervals centred on the frozen point
forecast,
\begin{equation}
    PI_{k,s,t}^{80}
    =
    \left[
        \widehat y_{k,s,t}-q_{k,s,t},
        \widehat y_{k,s,t}+q_{k,s,t}
    \right].
    \label{eq:pi80}
\end{equation}
The primary calibration method is domain specific.  For GDP, \(q_{k,s,t}\)
is the empirical 0.80 quantile of the most recent 20 absolute admissible
errors, with a minimum history of 12 errors.  The quantile uses the
``higher'' empirical order-statistic convention.

For inflation and labour, the primary method is an exponentially weighted
0.80 quantile of absolute admissible errors over a maximum window of 48
observations and a minimum history of 24.  Indexing the newest calibration
error by \(j=0\), inflation uses
\begin{equation}
    \omega_j^{\pi}
    \propto
    0.5^{j/18},
    \label{eq:h4_inflation_weights}
\end{equation}
while labour uses
\begin{equation}
    \omega_j^{L}
    \propto
    0.94^j.
    \label{eq:h4_labour_weights}
\end{equation}
For values \(v_j=|e_j|\), the weighted quantile is the smallest ordered value
whose cumulative weight reaches 80\% of total weight,
\begin{equation}
    q_{0.8}^{w}
    =
    \inf\left\{
        x:
        \frac{\sum_j \omega_j\I(v_j\leq x)}
             {\sum_j \omega_j}
        \geq 0.8
    \right\}.
    \label{eq:h4_weighted_quantile}
\end{equation}
There is no fallback interval: a target--stage forecast with fewer than the
predeclared minimum number of observable prior errors is H4-ineligible.
Evaluation is stage specific and does not impose complete-stage balancing.

\subsection{Interval benchmarks and evaluation}
\label{subsec:interval_metrics}

GDP's rolling empirical interval is compared with a conventional Gaussian
RMSE interval.  Inflation and labour additionally compare the primary
exponentially weighted interval with an unweighted rolling empirical
\(q_{0.8}\) interval.  The rolling benchmark uses the same 48-observation
window and 24-error minimum as the corresponding primary method and the same
``higher'' empirical quantile convention.  The Gaussian half-width is
\begin{equation}
    q_{k,s,t}^{G}
    =
    z_{0.90}
    \sqrt{
        \frac{1}{M}\sum_{i=1}^{M} e_i^2
    },
    \label{eq:h4_gaussian}
\end{equation}
where the errors are drawn from the same admissible calibration window and
the interval remains centred on the point forecast.  No bias correction is
applied.

Empirical coverage is
\begin{equation}
    Coverage
    =
    \frac{1}{N}\sum_{t=1}^{N}
    \I\left(L_t\leq y_t\leq U_t\right),
    \label{eq:coverage}
\end{equation}
with inclusive endpoints.  Coverage uncertainty is summarised by a 95\%
Wilson binomial interval.  Calibration diagnostics comprise likelihood-ratio
tests of unconditional 80\% coverage, independence of violations, and their
joint conditional-coverage implication.

Average interval width is
\begin{equation}
    AIW
    =
    \frac{1}{N}\sum_{t=1}^{N}(U_t-L_t).
    \label{eq:aiw}
\end{equation}
For nominal coverage \(1-\alpha=0.80\), the central Winkler interval score is
\begin{equation}
\begin{split}
    IS_{\alpha,t}
    ={}&(U_t-L_t)
    +\frac{2}{\alpha}(L_t-y_t)\I(y_t<L_t)\\
    &+\frac{2}{\alpha}(y_t-U_t)\I(y_t>U_t),
    \qquad \alpha=0.20.
\end{split}
\label{eq:interval_score}
\end{equation}
Lower scores indicate a better calibration--sharpness trade-off.  Pairwise
inference uses
\[
    d_t^{IS}
    =
    IS_t^{\mathrm{primary}}
    -
    IS_t^{\mathrm{benchmark}},
\]
so negative values favour the primary method.  The mean score differential
is tested using a Newey--West HAC standard error with Bartlett weights and
bandwidth
\begin{equation}
    B
    =
    \left\lfloor
        4\left(\frac{N}{100}\right)^{2/9}
    \right\rfloor.
    \label{eq:h4_hac_bandwidth}
\end{equation}
The H4 design, calibration windows, minimum histories, benchmark set, and
availability rule were frozen before confirmatory interval results were
observed.
